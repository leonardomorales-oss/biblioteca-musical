# Biblioteca Musical accesible

Catálogo con búsqueda, página de sugerencias, imágenes con texto alternativo y formulario accesible.

## Tecnologías

- React
- Vite
- HTML
- CSS

## Instalación y ejecución

```bash
npm install && npm run dev
```

```bash
npm run build
```

Comprobaciones disponibles: `npm run lint` y `npm run build`.

## Uso

Prueba búsqueda, sugerencias y formulario.
